# Caption Pack

## When to Use

- "Write a caption", "แคปชั่น", "hashtags for this", "ready to post".
- After an `ad-script` or `reel-breakdown`, when Chain wants to post.

## Procedure

1. **Inputs.** You need the video or post topic, the platform, the language (TH, EN, or both), the CTA, and the brand voice. Pull whatever's missing from memory or the current conversation before asking.
2. **Three captions:**
   - **Short**: 1 line.
   - **Medium**: 2–4 lines.
   - **Long**: a mini story with line breaks.

   The first line must work as a hook on its own, because that's the only line people see before "…more". End each caption with a clear CTA ("เซฟไว้", "คอมเมนต์ว่า X", "ทักแชท").
3. **Hashtags.**
   - 3–5 for TikTok, 5–10 for IG.
   - Mix broad, niche, and Thai-language tags.
   - No banned or spammy tags.
4. **Extras.**
   - One pinned-comment idea.
   - One idea for the cover text on the thumbnail.
5. **Both languages.** If Chain asked for TH+EN, write each language natively. Don't translate one into the other word for word.

## Output Shape

Send each caption in its own block so it's easy to copy on a phone. Put the hashtags on a separate line.

## Pitfalls

- Avoid emoji walls. Use at most 1–3 emoji per caption unless Chain's style says otherwise.
- Don't write engagement bait that the platforms penalise ("like if…", "tag 10 friends").

## Verification

The first line is under about 60 characters, every caption has a CTA, and the hashtag count fits the platform.
