# Hook Lab 🎬

Short-form ad script studio for Reels / TikTok / Shorts — English + ไทย.

Open `index.html` in Chrome. No install, no API key.

## What it does
- **Brief → script**: fill product, audience, pain, win, CTA → get a timed beat sheet (Hook / Problem / Solution / Proof / Payoff / CTA) for 15s, 30s or 60s.
- **12 proven hook formulas** in EN and TH. Tap one to swap it in.
- **Timing check**: estimates spoken length (Thai word segmentation included) and flags beats that are too long.
- **Shot list + on-screen text** for every beat.
- **Captions**: export a ready `.srt` file for CapCut / Premiere / Motion.
- **Teleprompter**: fullscreen scrolling script, speed + size, mirror mode, 3-2-1 countdown, space = play/pause.
- **Record in browser**: turn on the camera in teleprompter mode and record takes straight to a video file.
- **Library**: save scripts locally and reload them later.
